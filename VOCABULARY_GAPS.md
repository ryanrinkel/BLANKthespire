# Archetype & Vocabulary Gaps — Capture Log

When the creative harness maps a theme's concept clusters onto the archetype
catalog, it sometimes surfaces a mechanic the theme *wants* but the current
EffectRunner vocabulary **cannot express**. Instead of letting the generator
invent off-vocabulary card code (unsafe — breaks the closed-vocabulary
guarantee), the mapping stage **logs the gap here** for a human to evaluate and,
if it's good, implement later as a real op + schema entry + VOCABULARY.md row +
EffectRunner switch case.

**How this file is maintained:** the convergent/mapping stage appends any
concept that doesn't map cleanly to the catalog as a new entry below. A human
triages — promote good ones into the vocabulary, mark weak ones `rejected`.

Status values: `captured` (new, untriaged) · `planned` (accepted, queued to
build) · `building` · `done` (now in vocabulary) · `rejected`.
