How it works
  1. Subscribe to the mod on Steam Workshop (once).
  2. Pick how to pay: paste your own API key (free) or get a forge token (one token = one forge). The Forge button stays off until you do.
  3. Describe a class below and press Forge. You get a code.
  4. In Slay the Spire 2: Mods → BLANK the spire → Import a class code → paste → Import.
  5. Restart the game and pick your class.

We run it on our models. Each token is one forge: $3 → 2 tokens, $5 → 4, $10 → 10, or any whole amount from $11 at one token per dollar.

Advanced options

Normally the forge maps your theme onto the game's build engines (the archetypes) and picks the strongest combination itself. With Interactive forge on, it pauses once your theme is mapped, shows you the candidate engines, and lets you pick up to two of them. You get a short timer; if you don't answer, the forge decides for you.
