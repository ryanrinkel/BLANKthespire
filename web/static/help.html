Where do I paste my code?

Inside the game, not on this site. Forge a class here, copy its import code (it starts with BTSC.), then in Slay the Spire 2 open the main menu → Mods / mod settings → BLANK the spire → paste it into Import a class code and press Import. Restart the game and your class appears at character select.

Step by step

  1. Forge a class on the site and press Copy code. The code starts with BTSC. and ends with a short hash — copy all of it.
  2. Launch Slay the Spire 2 and open the main menu → Mods / mod settings.
  3. Choose BLANK the spire from the list of installed mods.
  4. Paste the code into "Import a class code" and press Import.
  5. Restart the game.
    The restart is REQUIRED. The mod will say so right after the import. A newly imported class is only loaded at startup — it will not appear at character select until you fully quit and relaunch the game.
  6. Start a new run and pick your class from the character select screen.

Troubleshooting

  • "Code rejected" / "invalid code". Make sure the whole code was copied — including the BTSC. prefix at the front and the short hash after the final dot. A code cut off at either end can't be decoded. The Copy code button always copies the whole thing.
  • The class doesn't appear at character select. You didn't restart. Quit the game completely and relaunch — imported classes only load at startup.
  • There's no Mods menu / the game isn't modded. The mod isn't installed yet — see Get the mod.
  • Anything else. Report a bug on GitHub. If the game crashed, include the lines from %APPDATA%\SlayTheSpire2\logs\godot.log.
